# C++ custom debugger example

This project serves as an example of how to use ImGui in ERS.
It contains no real model, but a placeholder meant to support the ImGui example.
Instead, the focus is on creating a custom debugger using the available [ERS ImGui widgets](https://docs.ers.incontrolsim.com/latest/core/ui/imgui_widgets/).
This debugger is similar to the [pre-built debugger in ERS](https://docs.ers.incontrolsim.com/latest/core/ui/debugger/), but adds a custom widget too.
